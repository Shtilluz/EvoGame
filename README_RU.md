# Симулятор Эволюции

Симулятор эволюционной биологии в реальном времени на Python + Pygame. Наблюдайте, как виды возникают, адаптируются и вымирают в результате естественного отбора — тик за тиком.

---

## Быстрый старт

```bash
pip install pygame
python main.py
```

**Управление**

| Клавиша | Действие |
|---------|----------|
| `Пробел` | Пауза / Продолжить |
| `F11` | Полноэкранный режим |
| `N` / `Н` | Добавить 8 травоядных |
| `X` / `Х` | Добавить 3 хищников |
| `S` / `С` | Добавить 5 падальщиков |
| `R` | Перезапустить симуляцию |
| `+` / `-` | Ускорить / замедлить |
| `Q` / `Esc` | Выход |
| **Клик** по животному | Открыть инспектор |

## Что происходит в симуляции

Симуляция начинается с **30 травоядных** и **6 хищников** в мире с 180 растениями и 5 источниками воды. Каждый тик каждое животное тратит энергию и гидратацию, принимает решение (бежать, пить, есть, бродить) и может размножиться. При размножении потомок может унаследовать изменённые трейты. После накопления достаточного числа мутаций возникает новый вид.

### Сезоны

Четыре сезона сменяют друг друга каждые 4 800 тиков (один игровой год). Сезон влияет на рост растений и давление отбора:

| Сезон | Рост растений | Спавн растений | Эффект |
|-------|--------------|----------------|--------|
| Весна | норма | ×1.2 | Умеренный |
| Лето | ×1.4 | ×2.0 | Пик — популяции растут |
| Осень | ×0.6 | ×0.55 | Начало упадка |
| Зима | −0.05/тик | ×0.08 | Растения вянут; холодовые потери при малом запасе жира |

Летом животные накапливают **жир**, зимой сжигают его. Чем меньше жира — тем сильнее потери от холода.

## Виды животных

### Травоядное (зелёный круг)

Базовый вид. Ест растения, убегает от хищников, сбивается в стада.

| Параметр | Диапазон по умолчанию |
|----------|-----------------------|
| Скорость | 0.9 – 2.2 |
| Зрение | 5 – 13 |
| Макс. энергия | 160 |
| Макс. возраст | 600 – 1 100 тиков |

**Приоритет поведения:** бегство → питьё → стадо → охота на мелкую добычу (при смещённом рационе) → еда растений → блуждание

### Хищник (красный ромб/треугольник)

Самый быстрый и опасный вид. Охотится на травоядных, падальщиков и всеядных. Зрение хищника учитывает камуфляж жертвы.

| Параметр | Диапазон по умолчанию |
|----------|-----------------------|
| Скорость | 1.6 – 3.2 |
| Зрение | 8 – 16 |
| Макс. энергия | 250 |
| Макс. возраст | 900 – 1 600 тиков |

**Приоритет поведения:** питьё → охота (с учётом камуфляжа) → пастьба (при смещённом рационе) → блуждание

### Падальщик (коричневый круг с ×)

Возникает только через мутацию травоядного. Специализируется на поедании трупов.

| Параметр | Диапазон по умолчанию |
|----------|-----------------------|
| Скорость | 0.6 – 1.5 |
| Зрение | 10 – 18 |
| Макс. энергия | 150 |
| Макс. возраст | 500 – 1 000 тиков |

**Компромиссы:** ×1.35 голод, лучшее зрение, вдвое меньше энергии от растений, не охотится на живых.

### Всеядное (золотой ромб)

Возникает только через мутацию. Ест и растения, и живую добычу; самый медленный класс.

| Параметр | Диапазон по умолчанию |
|----------|-----------------------|
| Скорость | 0.4 – 1.0 |
| Зрение | 7 – 14 |
| Макс. энергия | 170 |
| Макс. возраст | 700 – 1 200 тиков |

**Компромиссы:** ×1.10 голод, гибкость в питании, лёгкая добыча для хищников из-за малой скорости.

## Генетика и мутации

При каждом размножении у каждого мутируемого трейта есть шанс измениться на гауссовскую дельту:

| Трейт | Диапазон | Шанс мутации |
|-------|----------|--------------|
| Скорость | 0.3 – 5.0 | `mutation_chance` |
| Зрение | 2.0 – 20.0 | `mutation_chance` |
| Размер | 0.3 – 4.0 | `mutation_chance` |
| Стадность | 0.0 – 1.0 | `mutation_chance` |
| Рацион | 0.0 – 1.0 | `mutation_chance × 0.5` |
| Выносливость | 0.0 – 1.0 | `mutation_chance × 0.4` |

**Ось рациона:** `0.0` = чистый травоядный → порог `0.35` → зона всеядных → порог `0.65` → `1.0` = чистый хищник

**Компромисс выносливости:** высокая выносливость снижает голод и жажду (до 45%), но и уменьшает эффективную скорость (до 35%).

**Камуфляж:** RGB-цвет животного дрейфует вместе с мутациями. Чем ближе цвет к фону сезона — тем сложнее хищнику заметить жертву.

### Видообразование

Каждая унаследованная мутация увеличивает `mutation_count`. Когда счётчик пересекает `speciation_thresh` (по умолчанию 10), следующий потомок может стать новым видом:

- **→ Хищник** (6% при `рацион > 0.65`): скорость ×1.25, большой запас энергии
- **→ Падальщик** (22% при `рацион > 0.35`): зрение ×1.2, скорость ×0.82
- **→ Всеядный** (22% при `рацион > 0.20`): скорость ×0.60, смешанный рацион
- **→ Новый подвид травоядного** (иначе): `mutation_count` сбрасывается в 0

## Настраиваемые параметры (вкладка НАСТР)

Все параметры применяются немедленно каждый тик:

| Слайдер | Эффект |
|---------|--------|
| Шанс мутации | Вероятность мутации каждого трейта при рождении |
| Величина мут. | σ гауссовского сдвига |
| Голод трав. | Дополнительный расход энергии/тик у травоядных и падальщиков |
| Голод хищн. | Дополнительный расход энергии/тик у хищников |
| Жажда | Множитель потери гидратации у всех видов |
| Порог вида | Количество мутаций до возможного видообразования |

## Структура проекта

```
EvoGame/
├── main.py                  # Точка входа — игровой цикл, ввод, окно
├── constants.py             # Цвета, сезоны, пулы имён, границы трейтов
├── params.py                # SimParams (значения слайдеров) + Layout (геометрия окна)
│
├── animals/                 # По одному файлу на вид
│   ├── base.py              # Animal — движение, метаболизм, базовое размножение
│   ├── herbivore.py         # Herbivore — также управляет ветвлением в новые виды
│   ├── predator.py          # Predator
│   ├── scavenger.py         # Scavenger
│   └── omnivore.py          # Omnivore
│
├── world/                   # Неживые объекты мира
│   ├── plant.py             # Plant — источник энергии, растёт сезонно
│   ├── water.py             # WaterSource — статичный, животные пьют из него
│   └── corpse.py            # Corpse — разлагается, поедается падальщиками
│
├── simulation/
│   └── core.py              # Simulation — главный цикл обновления, история, журнал
│
├── ui/
│   └── slider.py            # Слайдер — полный и компактный режимы отрисовки
│
└── rendering/
    └── renderer.py          # draw_all() + draw_legend() — вся отрисовка pygame
```

## Добавление нового вида

1. Создать `animals/myspecies.py` — унаследовать от `Animal`, переопределить `_default_diet`, `update`, `spawn`, `draw`.
2. Добавить пул имён в `constants.py` и обработать новый kind в `new_species_name()`.
3. Добавить список в `Simulation.__init__` и обновить `Simulation.update` (блок четырёх видов).
4. Зарегистрировать новый тип в `rendering/renderer.py` для подсчёта и отрисовки.
5. Экспортировать из `animals/__init__.py`.

## Технические детали

- **Система координат:** вещественные ячейки сетки; рендеринг при `CELL = 8 пкс/ячейку`. Мир занимает ~70% окна; правая панель — ~30%.
- **Коллизии:** животные могут перекрываться; проверки близости используют евклидово расстояние в ячейках.
- **Производительность:** все списки пересоздаются каждый тик через list comprehensions; подходит для сотен животных при 60 FPS.
- **Система жира:** энергия выше 80% MAX_E конвертируется в жир (с небольшими потерями); жир сжигается с коэффициентом 1.5× при падении энергии ниже 30% MAX_E.
